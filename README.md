# 패스워드 가디언 — 프로토타입 0.1

Python Arcade로 만든 오프라인 1인용 보안 체험 게임입니다. 임시 에셋으로 안내 → 보안 선택 → 3단계 전투 → 결과 → 시작 화면까지 플레이할 수 있습니다.

## 실행

현재 개발 PC에는 실행에 필요한 Arcade가 설치되어 있습니다. **`start_game.bat`를 더블클릭**하거나 프로젝트 폴더에서 실행하세요.

```powershell
python run_game.py
```

| 조작 | 동작 |
|---|---|
| Enter | 시작 화면에서 게임 시작 |
| 방향키 | 이동(초당 620px), 공격은 자동 발사 |
| Shift (누르는 동안) | 정밀 이동(초당 240px), 실제 피격 점 표시 |
| Space | 주변 탄환 제거, 기본 3회 |
| 1 / 2 또는 숫자패드 1 / 2 | 보안 선택 |
| Esc | 일시정지 / 재개, 재개 전 3초 안내. 30초가 지나면 자동 재개 |
| F11 | 전체 화면 전환 |
| 창 닫기 / Alt+F4 | 프로그램 종료 |
| Esc(시작 화면) · Shift+Esc | `--booth`로 실행했을 때 게임 종료 |

```powershell
python run_game.py --fullscreen
python run_game.py --practice
python run_game.py --data-dir .\runtime\local-play
```

`--practice`는 전체 게임을 동일하게 플레이하되 결과를 랭킹에 등록하지 않습니다. 기본 창은 1280×720이며 화면 내부는 1920×1080 좌표를 사용합니다. 창 크기를 바꿔도 종횡비를 유지하고 남는 영역에 여백을 둡니다. 창을 다른 프로그램으로 전환하면 게임과 타이머가 멈춥니다.

## 다른 PC에 설치

검증 환경은 Windows, Python **3.14.3**, Arcade **3.3.3**, NVIDIA RTX 3090입니다. Python 3.11 이상을 설치한 Windows PC에서 아래와 같이 별도 가상환경을 만들 수 있습니다. 다른 Python 버전·그래픽 환경은 실제 부스 PC에서 다시 확인하세요.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_game.py
```

첫 의존성 설치에는 인터넷이 필요합니다. 설치 후 플레이와 랭킹은 인터넷 없이 동작합니다. `start_game.bat`(`run.ps1`)는 `.venv`가 있으면 그 Python을 씁니다. 없으면 처음 실행할 때 `.venv`를 직접 만듭니다: uv가 있으면 `uv venv --python 3.13`(필요하면 Python 3.13을 내려받음), 없으면 PATH의 Python 3.11~3.13으로 만들고 `requirements.txt`를 설치합니다. Arcade 3.3.3이 쓰는 pymunk 6.9.0은 Python 3.14용 설치 파일이 없으므로 3.13 이하를 쓰세요. 이미지·글꼴 경로는 실행 파일 위치를 기준으로 하므로 다른 폴더에서 실행해도 됩니다.

`src/`, `data/`, `assets/images/`, `assets/fonts/`, 실행 파일과 라이선스 문서를 함께 옮겨야 합니다. 한글은 함께 포함한 IBM Plex Sans KR 글꼴(SIL OFL 1.1)로 표시하므로 PC에 글꼴을 따로 설치하지 않아도 됩니다.

## 부스 런처용 실행 파일(.exe)

Python이 없는 부스 노트북용으로 **`build_exe.bat`를 더블클릭**하면 `dist\PasswordGuardian\PasswordGuardian.exe`(옆의 `PasswordGuardian.pkg` 파일, `_internal` 폴더와 함께 사용 — 백신이 실행 파일 읽기를 막아도 켜지도록 코드를 `.exe` 밖에 둡니다)와 `dist\PasswordGuardian.zip`이 만들어집니다. 처음에는 인터넷이 필요합니다. 런처에서는 `--booth --fullscreen`으로 실행합니다. `--booth`는 한 판이 끝나면(결과 화면 뒤) 스스로 종료하고, 시작 화면의 `Esc`와 운영진용 `Shift + Esc`로도 종료합니다. 오류로 꺼지면 종료 코드 1과 함께 데이터 폴더의 `error.log`에 내용을 남깁니다. 런처 담당자에게 전달할 내용은 [부스 런처 제출 정보](docs/부스_런처_제출정보.md)에 정리했습니다.

## 구현된 플레이

- 조작 연습 20초 + 본게임 180초 + 결과 40초. 일시정지와 시작 화면 대기 시간은 제외합니다.
- 각 단계는 선택·설명 8초와 전투 52초입니다. 6초 안에 선택하지 않으면 미선택으로 기록하고 정답을 설명합니다.
- 직선 공격 봇, 부채꼴 드론, 다방향 군단, 패턴이 바뀌는 보스가 등장합니다. 일렬·V자·양옆 진입 편대로 몰려오며 판당 1단계 약 42기, 2단계 약 53기, 3단계 보스와 약 28기입니다. 생성 시 테두리로 위치를 표시합니다.
- 보안 공격 적 6종이 단계마다 섞여 나옵니다. 1단계 비밀번호 스프레이 포대(한 비밀번호를 부채꼴로 쓸어 쏨)와 키로거 그림자(1.2초 전 위치를 노림), 2단계 트로이 선물 상자(열리기 전에 부수지 않으면 군단과 탄이 쏟아짐)·피싱 미끼선(아군처럼 보이다 정체를 드러냄)·어깨너머 감시자(노란 시야에 0.8초 머물면 쏨), 3단계 알림 폭탄 드론(로그인 승인 알림 8연발, 보스 처치 후 증원)과 어깨너머 감시자입니다. 판에서 처음 나올 때 전투 영역 위쪽에 이름과 보안 습관을 3초 동안 띄웁니다.
- 체력 소진 시 즉시 부활하고 100점 차감, 2초 무적을 적용합니다. 점수는 0 미만이 되지 않습니다.
- 적을 3기 처치할 때마다 정해진 순서로 아이템이 떨어집니다(운 요소 없음). 보스는 3개를 떨어뜨립니다. 화면 위쪽(높이 720 이상)으로 올라가거나 가까이 가면 끌려옵니다.

  | 아이템 | 효과 |
  |---|---|
  | 패치(초록 화살표) | 무기 단계 +1 |
  | 백업(하늘색 디스크) | 보호막 +1, 최대 3 |
  | 백신(흰 십자) | 방어 스킬 +1 |
  | 보안 배지(금색 별) | 100점 |
  | 방화벽(주황 벽돌) | 5초 동안 적 탄 속도 절반 |

  이미 최대인 효과는 100점으로 바뀝니다.
- 무기는 1~4단계로, 단계가 오를수록 발사 수가 늘고 4단계에서 유도탄이 더해집니다. 맞거나 부활해도 단계는 유지됩니다.
- 정답마다 200점과 보호막·공격력·스킬 강화가 적용됩니다. 틀려도 진행하고 이전 강화는 유지합니다.
- 일반 적 50점, 보스 500점. 보스를 일찍 잡으면 약한 적이 이어서 등장하며 전체 진행 시간은 유지됩니다.
- 결과에는 점수·게임 등급·처치·부활·선택 기록·학습 메시지와 로컬 순위가 나옵니다.

기체 5종, 추가 적 6종과 배경 5장은 생성형 AI로 만든 이미지입니다. 효과음·음악은 아직 적용하지 않았습니다.

## 부스 공통 결정 사항 (2026-10-19)

부스 노트북 4대에서 세 게임(클린 데이터 라벨러 · 데이터 패킷 러너 · 패스워드 가디언)을 런처로 함께 운영하며 다음을 정했습니다.

- **순위표는 노트북별로 독립**: 각 게임의 순위는 그 노트북에만 저장하고 노트북끼리 공유하지 않습니다(네트워크를 쓰지 않음). 노트북마다 TOP 10이 따로 생깁니다.
- **아케이드 버튼은 쓰지 않음**: 게임 조작과 이름 입력은 모두 노트북 키보드로 합니다.
- **랭킹 규칙 통일(2026-10-19)**: 세 게임 모두 오늘의 TOP 10, 영문 이니셜 3자, 공통 금칙어 119개, 게임 폴더 안 `data/` 저장을 씁니다.
- 이 게임의 순위 파일: 게임 폴더의 `data\ranking.json` (노트북마다 따로)

## 로컬 랭킹

**오늘의 TOP 10**을 시작 화면과 결과 화면에 보여 줍니다. 날짜가 바뀌면 새로 시작하며, 지난 기록은 파일에 남지만 보이지 않습니다. 순위는 점수 → 정답 수 → 적은 부활 → 먼저 달성한 순입니다. 현재 규칙 버전(`config.py`의 `RULESET`, 지금 `prototype-3`)의 기록만 셉니다.

**이니셜:** 결과 화면이 열리면 이번 점수가 오늘 몇 위인지 확인합니다. TOP 10에 들면 오른쪽에 입력 칸이 나오고 영문 이니셜 3글자를 입력합니다(A~Z, Backspace 지우기, Enter 저장, Esc 건너뛰기). 결과 화면이 열린 뒤 **25초 안에 저장하지 않거나 Esc로 건너뛰면 기록을 남기지 않습니다.** 3글자를 모두 채워야 저장되며, 부스 세 게임 공통 금칙어 119개(`src/password_guardian/names.py`, 다른 두 게임과 같은 목록)와 똑같은 이니셜은 "사용할 수 없는 이니셜" 안내만 나오고 저장되지 않습니다. 게임 창에서는 입력기(IME)를 꺼 두므로 한/영 키가 한글 상태여도 A~Z로 입력됩니다(클린 데이터 라벨러와 같은 방식). TOP 10 밖이면 입력 없이 "오늘 N위 · 10위는 몇 점"을 보여 주고 저장하지 않습니다. 결과 화면 40초 안에 입력과 순위표가 모두 들어가므로 한 판 시간은 그대로입니다.

기록은 게임 폴더의 `data\ranking.json`에 저장합니다(빌드한 exe는 `PasswordGuardian.exe` 옆 `data\`). 저장할 때마다 직전 파일을 `ranking.json.bak`으로 남기고, 임시 파일에 쓴 뒤 바꿔 끼우므로 전원이 꺼져도 반쯤 쓰인 파일이 남지 않습니다. 파일이 깨져 있으면 `ranking_broken_날짜.json`으로 옮기고 빈 순위로 시작합니다. 손으로 고치다 형식이 틀린 줄은 건너뜁니다. 행사가 끝나면 `data` 폴더의 `ranking*` 파일을 보관하거나 지우세요. 저장 작업은 별도 스레드에서 하며, 실패해도 결과 화면과 자동 복귀는 그대로 진행됩니다.

백업과 전체 초기화는 앱을 끈 뒤 명령으로 할 수 있습니다. 백업 경로는 기존 파일이 없는 새 경로여야 합니다.

```powershell
python run_game.py --backup .\runtime\ranking-backup-01.json
python run_game.py --reset-rankings --backup .\runtime\before-reset-01.json --confirm-reset
```

## 검증과 개발

```powershell
python -m unittest discover -s tests -v
python tools/smoke_test.py
```

첫 명령은 그래픽 창 없이 실행하는 규칙·DB 테스트 31개입니다. 두 번째는 실제 OpenGL 창을 보이지 않게 생성하여 240초 흐름을 10회 빠르게 시뮬레이션하고 화면을 캡처합니다. 약 40분의 실제 대기 시간을 측정하는 테스트는 아닙니다.

- 실행 기록: `runtime/smoke_report.json`
- 실제 렌더링 캡처: `runtime/screenshots/`
- 상세 검증 결과: [프로토타입 검증 기록](docs/PROTOTYPE_VALIDATION.md)

| 파일 | 역할 |
|---|---|
| `src/password_guardian/engine.py` | 타이머·웨이브·이동·탄막·충돌·부활 |
| `src/password_guardian/session.py` | 선택·점수·변경 불가능한 결과 데이터 |
| `src/password_guardian/app.py` | 화면·키보드 입력·SpriteList·창 크기 대응 |
| `src/password_guardian/rankings.py` | SQLite·백그라운드 저장·백업·초기화 |
| `data/choices.json`, `data/waves.json`, `data/attacks.json` | 보안 문항, 적 생성 시간표, 추가 적의 첫 등장 안내 문구 |
| `assets/images/sources.json` | 실제 사용한 임시 에셋의 원본·편집 내역 |
| `assets/fonts/` | 한글 글꼴 IBM Plex Sans KR 일반·굵게, 라이선스와 출처(`source.json`) |
| `assets/generated/` | 생성형 AI 기체·배경 원본과 출처(`source.json`) |

생성형 AI 원본(`assets/generated/`)에서 게임용 파일을 다시 만들 때는 `python tools/prepare_generated_assets.py`를 실행합니다. 기체는 생성 도구가 그려 넣은 가짜 체크무늬 배경과 'AI' 표시를 지우고 기체 경계로 잘라 표시 폭의 2배 크기 PNG로 저장합니다. 배경은 'AI' 표시가 있는 오른쪽 아래를 빼고(왼쪽 위 95%) 1920×1080 JPEG로 저장합니다. 이전 임시 에셋(`vault.png`, `player_bullet.png`)은 게임에서 쓰지 않으며 `python tools/prepare_prototype_assets.py`로 다시 만들 수 있습니다. 두 도구 모두 Pillow가 필요하며 게임 실행 시에는 필요하지 않습니다.
