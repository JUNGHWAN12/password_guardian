# 부스 런처 제출 정보 — 패스워드 가디언

‘부스 게임 런처 연동 안내(게임 제작자용)’(2026-10-19) 기준으로 런처 담당자에게 전달할 내용이다.

## 제출할 것

| 항목 | 내용 |
|---|---|
| 게임 이름 | 패스워드 가디언 |
| 한 줄 설명 | 계정을 노리는 공격을 막으며 비밀번호 습관을 익혀요 |
| 폴더 이름 | `PasswordGuardian` |
| 실행 파일 이름 | `PasswordGuardian.exe` |
| 실행 옵션 | `--booth --fullscreen` |
| 끝내는 방법 | 한 판이 끝나면(결과 화면 40초 뒤) 자동 종료. 시작 화면에서 `Esc`. 운영진은 언제든 `Shift + Esc`. 창 닫기·Alt+F4도 가능 |
| 한 판 시간 | 약 4분(조작 연습 20초 + 본게임 3분 + 결과 40초) |

`booth.json` 예시 항목:

```json
{"name": "패스워드 가디언", "description": "계정을 노리는 공격을 막으며 비밀번호 습관을 익혀요",
 "command": "../PasswordGuardian/PasswordGuardian.exe", "args": ["--booth", "--fullscreen"]}
```

## 만드는 법

Windows PC의 프로젝트 폴더에서 `build_exe.bat`를 더블클릭한다. `dist\PasswordGuardian\` 폴더와 `dist\PasswordGuardian.zip`이 생긴다. 이 폴더(또는 압축을 푼 폴더)를 `Booth\PasswordGuardian\`으로 복사한다. `PasswordGuardian.exe`와 `_internal` 폴더는 항상 함께 있어야 한다.

- 처음에는 인터넷이 필요하다(uv 또는 Python 3.11~3.13으로 실행 환경과 PyInstaller를 받는다). 만든 실행 파일은 Python이 없는 PC에서 인터넷 없이 동작한다.
- 이미지·글꼴·문항은 `_internal` 안에 들어 있고 실행 파일 위치를 기준으로 찾는다. 폴더 이름을 바꾸거나 옮겨도 된다.

## `--booth` 동작

| 상황 | 동작 |
|---|---|
| 결과 화면 40초가 끝남 | 결과를 랭킹에 저장한 뒤 종료(종료 코드 0). 런처 화면으로 돌아간다 |
| 시작 화면에서 `Esc` | 종료(0) |
| 게임 중 `Shift + Esc` | 운영진용 즉시 종료(0). 그 판은 랭킹에 저장하지 않는다 |
| 게임 중 `Esc` | 기존과 같은 일시정지. 30초 뒤 자동 재개하므로 관람객이 떠나도 판은 끝까지 진행된 뒤 종료된다 |
| 오류 | 오류 내용을 `%LOCALAPPDATA%\PasswordGuardian\error.log`에 남기고 종료 코드 1 |

조작 키(방향키, Shift, Space, 숫자 1·2, Enter, Esc)는 한/영 상태와 관계없이 동작한다. 콘솔 창은 뜨지 않는다.

## 저장 위치

랭킹은 노트북마다 게임 폴더의 `data\ranking.json`(`PasswordGuardian.exe` 옆)에 저장된다. 런처 폴더 `Booth\` 안에서 세 게임 모두 각자 폴더의 `data`만 정리하면 된다. 게임 폴더를 새 버전으로 바꿀 때는 `data` 폴더를 옮겨 두어야 그날 기록이 이어진다.

## 제출 전 점검

안내 문서의 점검 목록을 Python이 없는 다른 Windows PC에서 확인한다. 아래는 개발 환경(리눅스)에서 미리 확인한 것과 아직 남은 것이다.

- [x] 같은 레시피로 만든 실행 파일을 다른 폴더로 옮겨 실행(리눅스 빌드)
- [x] `--booth`: 시작 화면 Esc, 게임 중 Shift+Esc, 한 판 완료 뒤 자동 종료와 랭킹 저장(스모크 테스트)
- [ ] Windows에서 `build_exe.bat`로 만든 `PasswordGuardian.exe`가 Python 없는 노트북에서 켜지는지, 10초 안에 첫 화면이 뜨는지
- [ ] 명령 프롬프트에서 `PasswordGuardian.exe --booth`를 실행하고 시작 화면에서 Esc를 눌렀을 때 바로 프롬프트로 돌아오는지
- [ ] 한 판을 끝까지 하고 작업 관리자에 남은 프로세스가 없는지
