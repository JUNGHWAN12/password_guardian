# 프로토타입 0.1 검증 기록

검증일: 2026-10-12. 실행 환경: Windows, Python 3.14.3, Arcade 3.3.3, NVIDIA GeForce RTX 3090.

## 자동 검증 결과

`python -m unittest discover -s tests -v`: **30개 통과**.

- 안내·선택·전투·결과의 240초 시간표, 프레임이 상태 경계를 넘을 때 남은 시간 처리.
- 정답·오답·미선택, 중복 보상 방지, 연습 소모품 초기화, 결과 이후 점수 고정.
- 대각선 이동, 자동 발사, 보호막 우선 차감, 무적·부활, 스킬 범위와 재사용 제한.
- 비관통 탄환, 일반 적·보스의 단일 보상, 적·탄환 생성 상한.
- SQLite 재연결 후 기록 유지, 중복 세션 방지, 동점 정렬, TOP 10 밖의 순위, 버전별 기록 분리.
- 연습 기록 제외, 잘못된 점수 거절, 손상·미지원 DB 보존, 백업·초기화와 기존 백업 보호.

`python tools/smoke_test.py`: **10회 전체 세션 통과**.

- 실제 OpenGL 렌더링으로 시작·연습·선택·3단계 전투·결과·랭킹 화면 확인.
- 정답만 선택, 오답만 선택, 미선택을 번갈아 실행.
- 10개 완료 기록이 테스트 DB에 정확히 등록되고 다음 세션에서 전투 객체가 남지 않음을 확인.
- Space와 Esc의 누른 채 반복 입력 방지, 일시정지, 포커스 상실 시 키 초기화, 복귀 3초 안내 확인.
- 1024×768 창에서 16:9 화면 비율과 여백 처리 확인.
- 테스트 DB는 별도 임시 폴더에 생성·정리했으며 실제 운영 랭킹은 변경하지 않음.

10회 진행은 게임 시간을 빠르게 전달하는 자동 시뮬레이션이다. 40분 동안 사람이 조작한 현장 테스트 또는 전체 메모리 누수 검증을 대신하지 않는다.

## 화면과 성능

검증 도구가 생성하는 파일:

- `runtime/screenshots/title.png`: 시작 화면
- `runtime/screenshots/choice.png`: 보안 선택
- `runtime/screenshots/stage_1.png`~`stage_3.png`: 전투
- `runtime/screenshots/result.png`: 결과·순위
- `runtime/screenshots/leaderboard.png`: 10개 기록 표시
- `runtime/screenshots/letterbox_4_3.png`: 다른 화면 비율

적 20기·적 탄환 250발로 시작한 부하 장면을 90프레임 실행하고, 첫 10프레임을 제외한 업데이트·렌더링·GPU 완료 대기 시간을 측정했다. 해당 개발 PC의 1280×720 숨김 창에서 평균 **15.31ms**, 95백분위 **18.14ms**였다. 탄환은 측정 중 이동·제거되므로 250발을 항상 유지한 측정은 아니며, 실제 표시 FPS나 다른 부스 PC 성능을 보장하는 수치는 아니다.

## 남은 확인

- 실제 초보자 3명 이상으로 난이도·설명 읽기 시간·보스 회피 체감 조정.
- 실제 부스 화면·전체 화면 모드에서 입력, 가독성, 절전 설정, 장시간 실행 확인.
- 운영 환경에서 읽기 전용 저장 경로·디스크 부족 등 오류 상황 확인.
- 사용자 참고 보드에 맞춘 최종 원화 17종(보호막 도형 사용 시 16종), 사운드와 배포용 글꼴·EXE.

프로토타입은 기능과 흐름 검증을 위한 임시 에셋을 사용한다. 보안 학습 문구와 로컬 랭킹을 포함한 플레이 가능한 첫 버전이며 최종 부스 배포본은 아니다.
